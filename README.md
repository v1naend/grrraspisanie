## ✨ Возможности

- **Чередование недель.** Неделя 1 начинается 12.10.2026, дальше недели идут по очереди.
- **Половинки пар.** Ячейка пары разделена пополам: верхняя часть — первые 45 минут, нижняя — вторые 45 минут.
- **Перерывы.** Между парами 15 минут, между половинками одной пары 10 минут, обед 11:35–12:15, большой перерыв 15:50–16:20.
- **Изменения в расписании.**
  - 🟩 зелёная рамка — доставленная пара;
  - 🟥 красный пунктир и зачёркивание — отменённая пара.
- **Праздничные дни** выделены красным, занятия в этот день помечены как отменённые.
- **Удобно на телефоне.** На узком экране показывается один день, дни переключаются кнопками Пн–Сб.
- **Тёмная тема.** Страницы автоматически подстраиваются под тему устройства.
