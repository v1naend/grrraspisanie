## ✨ Возможности

- **Чередование недель.** Неделя 1 начинается 12.10.2026, дальше недели идут по очереди.
- **Половинки пар.** Ячейка пары разделена пополам: верхняя часть — первые 45 минут, нижняя — вторые 45 минут.
- **Перерывы.** Между парами 15 минут, между половинками одной пары 10 минут, обед 11:35–12:15, большой перерыв 15:50–16:20.
- **Изменения в расписании.**
  - 🟩 зелёная рамка — доставленная пара;
  - 🟥 красный пунктир и зачёркивание — отменённая пара.
- **Праздничные дни** выделены красным (07.11 — День Октябрьской революции), занятия в этот день помечены как отменённые.
- **Удобно на телефоне.** На узком экране показывается один день, дни переключаются кнопками Пн–Сб. На компьютере видна вся неделя целиком.
- **Тёмная тема.** Страницы автоматически подстраиваются под тему устройства.

## 🛠 Как обновлять

Всё расписание описано в начале скрипта на странице. Чтобы внести правки, нужно изменить один из блоков:

| Блок | Назначение |
|---|---|
| `A` и `B` | Базовое расписание 1-й и 2-й недели (пн–сб) |
| `ADD` | Доставленные пары по датам |
| `DEL` | Отменённые пары по датам |
| `HOL` | Праздничные дни |

Формат пары: `[номер пары (0–4), часть (0 — первая половина, 1 — вторая, 2 — вся пара), 'Предмет', 'Аудитория']`.

Пример доставленной пары, 90 минут, 4-я пара:

```js
'19.11': [[3, 2, 'Охрана труда', '308']]
```
